# 画面遷移とレイアウト

## ゲームフロー

```
タイトル
  ↓
キャラクター選択
  ↓
バトル（ランダム敵）
  ↓ 倒す
報酬（カード2枚から1枚選択）
  ↓ 一定確率
休憩所（回復 or カード強化）
  ↓
次のバトル（敵が強くなる）
  ↓
...繰り返し（ローグライク）
```

---

## キャラクター選択画面

```
┌─────────────────────────────────────┐
│                                     │
│          [ゲームタイトル]            │
│                                     │
│   ┌───────────┐   ┌───────────┐    │
│   │           │   │           │    │
│   │  [立ち絵] │   │  [立ち絵] │    │
│   │  剣士     │   │  忍者     │    │
│   │           │   │           │    │
│   │ 初心者向け│   │ 上級者向け│    │
│   └───────────┘   └───────────┘    │
│                                     │
└─────────────────────────────────────┘
```

- 左: 剣士（初心者向け）
- 右: 忍者（上級者向け）
- ホバーで枠が光る、クリックで決定
- 説明文なし。シンプルに2択のみ

## 休憩所画面

### ビジュアルコンセプト
クロノトリガーの時の回廊をイメージした**異次元の休憩所**。

### 背景
- 深い紺・紫のグラデーション
- 星・光の粒がゆっくり漂うアニメ
- 時空が歪むような薄いゆらぎエフェクト

### レイアウト
```
┌─────────────────────────────────────┐
│  ✦    ·    ✦    ·    ✦    ·    ✦   │
│    ·           ·           ·        │
│         ✦           ✦              │
│                                     │
│           [ヒロインの立ち絵]         │
│                                     │
│  ┌─────────────────────────────┐   │
│  │  ◉ HPを回復する（+20HP）    │   │
│  │  ◉ カードを強化する         │   │
│  └─────────────────────────────┘   │
│                                     │
│  ✦    ·    ✦    ·    ✦    ·    ✦   │
└─────────────────────────────────────┘
```

- 立ち絵はデッキ確認画面と共有（素材1枚で2画面に使用）
