# カードデザイン

```
╭──[装飾]──────────[装飾]──╮

│ ·──────────────────────· │

╰──[装飾]──────────[装飾]──╯
```

---

## カードタイプ

| タイプ | 内容 |
|---|---|
| ATTACK | ダメージを与える |
| SKILL | バフ・デバフ・シールドなど |
| POWER | 永続効果（バトル中ずっと有効） |

---

## キャラクター別枠デザイン（ミュシャ・アール・ヌーヴォー風）

### メインヒロイン（剣士）
- 装飾モチーフ: 月桂樹・剣・唐草
- 雰囲気: 重厚・騎士的

### 忍者
- 装飾モチーフ: 蓮・霞・水紋
- 雰囲気: 繊細・幻想的

キャラクターのモチーフはレア度に関わらず維持する。枠の豪華さだけがレア度で変わる。

---

## レア度（4段階）

| レア度 | 枠カラー | 装飾密度 | 特殊効果 |
|---|---|---|---|
| コモン | `#8a7a6a`（古びた銅） | シンプルな唐草 | なし |
| アンコモン | `#a8c5da`（銀） | 少し複雑な草花 | なし |
| レア | `#c8a951`（金） | 豪華な装飾＋宝石 | 淡い輝きエフェクト |
| レジェンド | `#c084fc`（紫・虹） | 全面装飾＋キャラモチーフ全開 | フレーム発光アニメ |
