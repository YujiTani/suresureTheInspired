## エリア別仕様

### 敵エリア（上半分）
- 敵イラストを画面中央に大きく表示（ウィザードリー式）
- HPバーは敵名の下
- Intent（次の行動予告）をHPバー下に常時表示
- バフ・デバフアイコンは敵イラストの**足元**に配置

### プレイヤーステータス（中段）
| 左側 | 右側 |
|---|---|
| ❤ HP（現在/最大） | バフアイコン（小・3列折り返し・積み上がり） |
| 🛡 シールド値 | |
| ⚡ エネルギー（現在/最大） | |

### カードエリア（下段）
- **左端**: 山札アイコン（小）＋枚数。クリックで一覧ポップアップ
- **中央**: 手札（最大5枚）
- **右端**: 捨て札アイコン（小）＋枚数。クリックで一覧ポップアップ
- **右下**: ターン終了ボタン

---

## カードホバー時の拡大表示
- 表示位置: 画面中央左寄り
- 演出: ジャキーンと出現（スライドイン）
- ホバー元カードの真上・中央に重ならない位置
