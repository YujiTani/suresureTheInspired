# Claude Design プロンプト：カードデザイン単体

以下をClaude Designにそのまま貼り付けて使用する。

---

## プロンプト本文

ダークファンタジーカードゲームの**カード単体**のデザインを作ってください。
5枚のカードを横並びで見せてください（手札として並べた状態）。

---

### カード1枚の情報構成（上から順）

1. **コスト**（左上、金色の丸バッジ）
2. **カード名**（右寄り、日本語）
3. **イラストエリア**（カード面積の40%、中央）
4. **効果テキスト**（日本語のみ。英語テキストは不要）
5. **タイプ**（中央下、ATTACK / SKILL / POWER）

英語の説明文・サブテキストは一切表示しないでください。

---

### 枠デザイン（最重要）

アルフォンス・ミュシャのアール・ヌーヴォースタイルで装飾された枠にしてください。

- 枠の上下左右に**有機的な曲線の唐草・草花・月桂樹**のモチーフ
- 装飾は枠の内側に向かって伸びる植物のつる
- 四隅に特徴的なアール・ヌーヴォーの装飾飾り
- 枠の線は細く繊細に、でも**はっきり視認できる明るさ**で
- 背景が暗いので、枠装飾は**明るめの色**にして埋もれないようにする

---

### 雰囲気・スタイルキーワード

- アール・ヌーヴォー / ミュシャ風 / 繊細な有機的装飾
- ダークファンタジー / ゴシック
- 枠装飾は**暗い背景に映える明るさ**で
- カード全体のサイズ感はトレーディングカードゲームの縦長比率（幅:高さ = 2:3）
