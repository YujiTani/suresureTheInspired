# Claude Design プロンプト：バトル画面

以下をClaude Designにそのまま貼り付けて使用する。

---

## プロンプト本文

ダークファンタジーのローグライク・デッキ構築カードゲームのバトル画面をデザインしてください。
世界観：悪魔退治をテーマにした重厚なダークファンタジー。
参考作品：Slay the Spire 2（UIの情報設計）、ウィザードリー（敵の表示方式）。

---

### 画面の役割

バトル画面です。ウィザードリーのように**敵が画面中央に大きく表示**されます。
プレイヤーキャラクターは画面上に表示されません。

---

### 全体レイアウト

画面を縦に3分割してください。

```
┌─────────────────────────────────────────┐
│                                         │
│  【敵エリア】上部40%                     │
│  敵名・HPバー・Intent・イラスト・バフ     │
│                                         │
├─────────────────────────────────────────┤
│  【プレイヤーステータス】中段15%          │
│  左:HP/シールド/エネルギー  右:バフアイコン│
├─────────────────────────────────────────┤
│                                         │
│  【カードエリア】下段35%                 │
│  山札 | 手札5枚 | 捨て札 | ターン終了    │
│                                         │
└─────────────────────────────────────────┘
```

---

### 各エリアの詳細

**敵エリア（上部）**
- 敵名「堕落の魔犬」を上部に表示
- HPバー：72/80（テキストとバー両方表示）
- Intent（次の行動予告）：⚔ 8ダメージ と表示
- 敵イラストエリアを画面中央に大きく確保（イラストはプレースホルダーでOK）
- バフ・デバフアイコンは敵イラストの**足元**に配置

**プレイヤーステータス（中段）**
- 左側：❤ HP 72/80、🛡 シールド 5、⚡ エネルギー 2/3 を縦に並べる
- 右側：バフアイコンを小サイズで**3列**に並べ、超えると折り返して積み上がる形式

**カードエリア（下段）**
- 最左端：山札アイコン（小）＋「32」枚数表示
- 中央：手札5枚を横並びで配置（下記サンプルデータ参照）
- 最右端：捨て札アイコン（小）＋「8」枚数表示
- 右下コーナー：「ターン終了」ボタン

---

### カードのビジュアルデザイン

**レイアウト（上から順）**
1. コスト（左上）＋ カード名（右）
2. イラストエリア（プレースホルダーでOK）
3. 効果テキスト
4. タイプ（ATTACK / SKILL / POWER）を中央下

**枠装飾**
アルフォンス・ミュシャのアール・ヌーヴォー風の有機的な曲線装飾を枠に施してください。
モチーフ：月桂樹・剣・唐草。雰囲気：重厚・騎士的。
細部は簡略化しても構いません。

**レア度による枠色**
- コモン：`#8a7a6a`（古びた銅色）
- アンコモン：`#a8c5da`（銀色）
- レア：`#c8a951`（金色）
- レジェンド：`#c084fc`（紫・虹）
