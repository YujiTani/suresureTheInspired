# 忍者キャラクター設計書

## 基本コンセプト
- 難易度: アドバンスト（上級者向け）
- 戦闘スタイル: **耐えて、蓄積して、必殺の一撃で仕留める**
- 序盤は弱く、生き残るほど指数的に強くなるスノーボール設計

---

## パッシブ：気錬成

毎ターン開始時に自動発動。**気（ki）スタック**を蓄積する。

```typescript
// 統一気獲得エンジン（全ての気獲得アクションがこれを使う）
function gainKi(player: Player, baseAmount: number): number {
  const multiplier = 1 + Math.floor(player.ki / 10);
  return baseAmount * multiplier;
}
// パッシブはbaseAmount=1で呼ぶ
```

| 気の合計 | ターン獲得量（パッシブ） |
|---|---|
| 0〜9 | +1 |
| 10〜19 | +2 |
| 20〜29 | +3 |
| 30〜39 | +4 |
| 50〜 | +6〜 |

**気スタックに上限なし。** 溜めるほど加速する。

## 必殺技ダメージ式

```typescript
const ultimateDamage = Math.floor(player.ki * player.ki * 0.5);
// ki=10 → 50ダメ
// ki=20 → 200ダメ
// ki=30 → 450ダメ
```

## カード一覧

### 防御・幻惑系
| カード名 | コスト | 効果 |
|---|---|---|
| 霧隠れ | 1 | このターン、次の攻撃を1回回避 |
| 幻影残像 | HPコスト+1 | 分身生成。次のダメージを身代わりが受ける |
| 惑わしの霧 | 1 | 敵の次の攻撃を弱体化-2＋命中率低下 |
| 幻惑 | 2 | 敵を「混乱」状態に（次ターン行動不能） |

### 気蓄積系
| カード名 | コスト | 基本ki獲得 |
|---|---|---|
| 気を練る | 0 | +2（乗数適用） |
| 瞬身 | 1 | +1＋1ドロー（乗数適用） |
| 影縫い | 2 | 敵を2ターン行動不能＋+3気（乗数適用） |

### 必殺系
| カード名 | コスト | 効果 |
|---|---|---|
| **奥義・滅影斬** | 全エネルギー | `ki² × 0.5`ダメージ。次ターン行動不能。気スタック全消費 |

## 序盤難易度設計

- ki=0〜9の間は乗数×1のまま → 攻撃力が低い
- 敵が一定ダメージを削り続けるプレッシャー
- **生存手段**：防御カードを引く or HPを消費して分身を使う
- 必殺技は「確実に仕留められる」確信がある時だけ使う設計
