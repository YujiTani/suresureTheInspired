# メインヒロイン設計書

## 基本コンセプト
- 難易度: ノーマル（初心者向け）
- 戦闘スタイル: **大剣による力強い直接戦闘**
- 役割: ゲームの基本3要素（攻撃・防御・コスト）を自然に教えるチュートリアルキャラ
- やり込み要素: 相殺システムにより上級者ほど輝く設計

---

## やり込み要素：相殺システム

敵のintent（予告ダメージ）とカードのダメージが一致すると発動。

| 差分 | 結果 |
|---|---|
| ぴったり一致 | ダメージ完全無効 + 攻撃ダメージ2倍 |
| ±2以内 | ダメージ半減 + 通常攻撃 |
| それ以外 | 通常（ブロックなし） |

### 演出（カットイン）

```
敵攻撃宣言 → 一致カード選択
  → 暗転 or フラッシュ
  → ヒロインカットイン（立ち絵・素材は後で追加）
  → ランダムセリフ
  → 爽快SE
  → 「相殺！」テキスト + ダメージ0演出
```

**セリフ一覧**
- 見切り系: 「見える！！」「読めた！」「そこだ！」
- 反撃系: 「そこっ！！」「もらった！」「隙あり！」
- 挑発系: 「甘い！！」「その程度？」「遅い！」

### 雑魚 vs ボスの差別化

- **雑魚**: intent固定 → 一致しやすい → カットイン頻発 → 爽快感
- **ボス**: intentにランダム幅あり（例: 8〜14）→ 相殺狙いが安定しない → 別戦略が必要
